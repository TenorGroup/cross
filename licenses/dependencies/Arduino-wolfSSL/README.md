`third_party/wolfssl/`, version 5.9.2. `COPYING` and `LICENSING` in this directory
are verbatim copies from that source tree. Its source provenance is recorded in
`third_party/wolfssl/PROVENANCE.md`.

separately in `licenses/historical/v1.0.1/Arduino-wolfSSL/`.
